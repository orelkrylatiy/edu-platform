# Learning Workspace course content

This branch is the independent public course source. Edit `content/courses/*.json` (stable IDs) or the three authoritative System Analyst Markdown files. No application deployment is triggered by this branch. Only public educational material belongs here; never commit learner state, credentials or private Wiki exports. Keep existing course/lesson/task IDs and review changes before publishing. See `docs/content.md` on main for the course contract.
