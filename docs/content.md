# Content contract

Course JSON in content/courses is public-safe. Each course has id, title, description, skills (array of strings), lessons (ordered array). Lessons have stable id, title, module, minutes, body (Markdown), tasks (id, text, optional, type). Never change existing identifiers when editing copy. Optional tasks do not affect completion. Private additions can be mounted in content/private, gitignored. A private file with the same filename overrides the corresponding public course. Run the local importer below only on a trusted copy of the Wiki. Replace or add lessons by editing files and redeploy; no runtime writes to course sources. Use unique IDs. Do not export private vault material to this public repository.

The sample System Analyst track is an original scaffold; it is not a verbatim copy of the private Wiki. Expand it after review. AI sees the selected lesson/task, saved lesson answers, notes, recent history, and up to eight same-module artifacts; planner sees bounded progress. It does not have repository access. The frontend course is a small scaffold.

Local import: `python scripts/import_roadmap.py /path/to/Middle\ System\ Analyst\ Roadmap.md`. The generated file is ignored by Git. The importer maps days and checkbox order into stable IDs for the imported edition; import before studying or deliberately migrate earlier demo progress. Future edits to tasks must retain existing IDs.
